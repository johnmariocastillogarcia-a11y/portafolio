# Portafolio de John Mario Castillo García
Hecho con React + TypeScript + Vite.

## Usar
```
npm install
npm run dev      # desarrollo
npm run build    # producción
```
## Publicar en GitHub Pages
1. Sube el proyecto a un repositorio de GitHub (rama `main`).
2. En Settings → Pages → Source elige **GitHub Actions**.
3. Cada push a `main` publica el sitio automáticamente.

Edita tu información en `src/data.ts`.
